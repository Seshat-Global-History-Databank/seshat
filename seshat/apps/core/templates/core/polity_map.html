How to use Seshat Maps

🔹 Use the slider at the bottom of the map to adjust the displayed year.

🔹 Use the play controls to quickly increment the year and animate the map through time.

🔹 Switch between a Globe and a Mercator map projection with 🌍.

The settings gear (⚙️) can be used to access additional controls:

🔹 Use the "Enter year" box to quickly navigate to a specific year.

🔹 Use the "Play rate" box to set the rate of the animation (and the skip controls increment).

🔹 Use the opacity slider to adjust the transparency of the polity shapes.

🔹 Use the "Choose base map" dropdown to switch between different base maps.

🔹 Learn more about the polity border choices.
